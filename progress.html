Progress

Your progress is saved in this browser. Download it as algolingo_progress.json to keep it in the repo, hand it to an LLM, or move it to another device. A copy of that file in the repo is read on every page, so edits to it show up here.

How the file works

  1. Browser to file: press Download, and save it as algolingo_progress.json at the top of the repo.
  2. File to browser: every page reads that file and adds anything marked "done": true. Open it on another device, or after an LLM edits it, and the ticks appear.
  3. LLM: point it at the file and your own checklist, and ask it to set "done": true and a "date" for whatever is finished. The format is in PROGRESS.md.
  4. Undo: a file only adds progress. To make a device match the file exactly, import it with Replace.
